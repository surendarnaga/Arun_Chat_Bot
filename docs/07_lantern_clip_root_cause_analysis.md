# Lantern Clip Root Cause Analysis
Author: Supplier Quality Engineering
Date: 2026-05-21
Plant: Coventry
Type: Root Cause Analysis

A detailed investigation was completed for the lantern clip issue found during vehicle trim validation.

Root cause summary:
- Tool wear at the supplier line caused dimensional variation in the clip legs.
- Retention force dropped below the approved threshold after thermal cycling.
- The issue was reproduced in 3 of 3 suspect batches and not reproduced in the control batch.

Actions:
- Supplier tooling recalibration completed.
- Incoming inspection updated with a retention force spot check.
- Validation team asked to verify the corrected batch in the next gate review.
